# content-inbox/

Staging only. Drop zone for unprocessed material after initial discovery:
raw photos, client-sent documents, notes, screenshots. Never a publish
source — verify provenance, optimize shippable media, and promote approved
material into the canonical content and asset folders
(`src/content/blog/<slug>/`, `src/assets/<type>/<slug>/`) before it ships.

Anchored in `.gitignore` as `/assets/` at the project root, so raw staging
never collides with or hides `src/assets/`.

No rooms scaffolded yet. Add focused subfolders (e.g. `assets/`,
`blog-material/`) only when real material starts arriving — this project's
current blockers (photography, Dr. Staehling's own words, insurance data,
smile gallery cases) are exactly what will land here first.
