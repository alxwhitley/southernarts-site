# pages/

Copy contracts for every fixed route, one file per page: `[slug]-copy.md`.
Section order, headings, body, CTAs, and open items. This is Claude chat's
output from PRE-1b, not Impeccable's.

Written so far: `home-copy.md`.

Every other route in `structure.md`'s sitemap needs its own `[slug]-copy.md`
here before `/impeccable craft` can run against it. No copy file, no craft.

Repeatable content (the `blog` collection) does not live here — see
`src/content/blog/<slug>/index.md` instead, per `structure.md`'s
repeatable-content decision.
